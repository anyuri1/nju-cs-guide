# 竞赛

竞赛是训练方式，不是勋章商店。先问它能不能逼你掌握一种能力、完成一个作品或认识一群靠谱的队友，再问能不能加分。

## 程序设计

- [ICPC](https://icpc.global/)：国际大学生程序设计竞赛官方入口。
- [CCPC](https://ccpc.io/)：中国大学生程序设计竞赛官方入口。
- [CCF CSP](https://www.cspro.org/)：认证报名、规则与成绩查询。
- [蓝桥杯](https://dasai.lanqiao.cn/)：门槛相对友好的个人赛；组别、语言和赛程以当届规则为准。
- [Codeforces](https://codeforces.com/)、[洛谷](https://www.luogu.com.cn/) 与 [AtCoder](https://atcoder.jp/)：日常训练和线上比赛平台。

## 方向型竞赛

- [Kaggle Competitions](https://www.kaggle.com/competitions)：数据与机器学习竞赛；先做 Getting Started，再看公开 notebook。
- [CTF Wiki](https://ctf-wiki.org/) 与 [picoCTF](https://picoctf.org/)：安全竞赛的知识索引与新手赛场。
- [全国大学生数学建模竞赛](http://www.mcm.edu.cn/) 与 [MCM/ICM](https://www.comap.com/contests/mcm-icm)：建模、编程和写作的组队训练。
- [中国国际大学生创新大赛](https://cy.ncss.cn/) 与 [挑战杯](https://www.tiaozhanbei.net/)：项目型赛事；先读评审规则，再决定是否值得投入。

学校和学院对竞赛的认定口径会变化。涉及奖学金、推免或评奖时，只认当年官方目录，不认培训机构的“含金量排名”。

## 怎么选

- 想练算法：固定参加周赛，三个月后再决定是否长期投入 ICPC/CCPC。
- 想做 AI：先完成一门机器学习课程和一个基线，再进 Kaggle。
- 想学安全：在合法靶场练习，从 picoCTF 或 pwn.college 开始。
- 想练协作与表达：数模或项目型赛事更直接，但队友和问题选择比比赛名字重要。

一次比赛结束后，留下题解、代码、实验记录或复盘。奖状会进文件夹，能力得留在你身上。
