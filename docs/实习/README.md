# 实习

第一段实习最难的地方通常不是“不会八股”，而是简历上没有一件能被追问十分钟的事。课程大作业、开源贡献、科研复现都可以成为项目，前提是你真的做过并留下证据。

## 去哪里找

- [南京大学学生就业创业指导中心](https://job.nju.edu.cn/)：校内宣讲、双选会、实习和就业手续。
- [国家大学生就业服务平台](https://www.ncss.cn/)：教育部建设的招聘与就业服务入口。
- [牛客](https://www.nowcoder.com/)：技术岗校招、笔试和面经聚合；经验帖要看发布日期。
- 目标公司的招聘官网：岗位要求、城市、流程和截止时间以公司页面为准。
- 老师、实验室和学长学姐：适合获取具体团队的信息；内推只能把简历送进去，不能替你通过面试。

不要只搜“实习”。同时搜岗位名、技术方向、城市和公司；建立表格记录链接、投递时间、进度和复盘。

## 简历

简历是证据的索引，不是自传。

- 一页足够。把与岗位最相关的项目放在上半页。
- 每段项目写清：要解决的问题、你负责的部分、关键技术选择、可以核验的结果。
- 数字只写能解释口径的数字。“性能提升 80%”会立刻得到下一个问题：和谁比，怎么测？
- GitHub 项目至少应有 README、运行方法、基本测试和清楚的提交历史。
- 不熟的技术不要塞进“技能”一栏。面试官很可能就从那里开始问。

可参考 [The Tech Resume Inside Out](https://thetechresume.com/) 的免费在线版和 [GitHub Docs：About READMEs](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)。模板只负责排版，内容仍要自己负责。

## 准备技术面试

- [Tech Interview Handbook](https://www.techinterviewhandbook.org/)：从简历、算法到行为面试的免费路线。
- [LeetCode](https://leetcode.cn/problemset/)：按专题练，不要按题号漫游；每题写复杂度并隔天重做。
- [Hello 算法](https://www.hello-algo.com/) 与 [代码随想录](https://programmercarl.com/)：前者补数据结构直觉，后者提供专题顺序。
- [CS 自学指南](https://csdiy.wiki/)：项目和专业基础薄弱时，回到对应课程补，而不是继续背问答。

常见准备顺序：语言基础 → 数据结构与算法 → 操作系统、网络、数据库 → 项目深挖 → 岗位相关知识。不同岗位会改权重，不会取消基本功。

## 时间

- 大一：学会 Git 和调试，认真做一个课程项目；
- 大二：补专业基础，做一个能公开展示的完整项目，开始看岗位描述；
- 大三上：整理简历并进行小规模投递，找出缺口；
- 大三寒假到春季：集中投暑期实习；具体批次以公司官网为准；
- 暑期：做事、记录、复盘；争取转正，但别把口头承诺当 offer。

投递没有神秘学。岗位会关，简历会沉，面试会失败。把每次失败变成下一周能修的一件事，就已经在向前走。
