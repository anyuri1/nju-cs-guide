# 科研

本科科研不是“找个组挂名”，也不是尽快凑出一篇论文。它更像一次长期实习：在一个没人知道标准答案的问题上，学会查证、实验、写作和合作。

## 进组以前

先做四件事：

1. 在[计算机学院](https://cs.nju.edu.cn/)师资页面找两三个真正感兴趣的方向；
2. 看老师近三年的论文题目，不要只看实验室简介；
3. 选一篇读到能说清“问题、方法、证据”；
4. 用一页简历和一封短邮件说明你做过什么、读了什么、每周能投入多久。

“老师您好，我对人工智能感兴趣”没有提供任何可回答的信息。具体到一篇论文、一个疑问或一个复现实验，谈话才会开始。

- [Research Starter Kit](https://github.com/LAMDA-NeSy/Research-Starter-Kit)：南大 LAMDA-NeSy 整理的中文科研入门指南，覆盖检索、阅读、想法、写作和 rebuttal。
- [How to Read a Paper](https://svr-sk818-web.cl.cam.ac.uk/keshav/papers/07/paper-reading.pdf)：三遍阅读法的原文。目标不是逐字翻译，而是逐步决定要不要继续投入。
- [南京大学创新训练计划](https://jw.nju.edu.cn/24762/list.htm)：大创与创新训练的官方入口；年份和申报条件以当期通知为准。

## 找论文

- [Google Scholar](https://scholar.google.com/)：宽检索、引用追踪与作者主页。
- [DBLP](https://dblp.org/)：核对计算机论文的作者、会议、年份和版本。
- [Semantic Scholar](https://www.semanticscholar.org/)：相关工作与引用脉络。
- [arXiv](https://arxiv.org/)：预印本入口；“挂在 arXiv”不等于经过同行评审。
- [CCF 推荐国际学术会议和期刊目录](https://www.ccf.org.cn/Academic_Evaluation/By_category/)：了解国内常用的目录口径，不要把分级当作论文质量的自动判定器。

常用检索法：先找近两年的综述或领域教程，再顺着参考文献找奠基工作，最后用“被引用”找后续。搜到一百篇不是进展，筛出五篇并说明为什么才是。

## 管论文和实验

- [Zotero](https://www.zotero.org/)：文献库、PDF 标注、引用键和共享组。
- [Connected Papers](https://www.connectedpapers.com/)：用一篇种子论文观察相近工作；它是地图，不是检索结果的裁判。
- [Papers with Code](https://paperswithcode.com/)：查论文、实现和数据集；仓库能跑起来仍不等于结果可复现。
- [Weights & Biases 学术资源](https://wandb.ai/site/research/)：实验记录与可视化的教程。简单项目用 CSV、配置文件和 Git 也足够。

一个可复现实验至少要留下：代码版本、环境、数据版本、随机种子、运行命令、指标定义和失败结果。只保存最好的一张图，等于没有实验记录。

## 写与说

- [Writing for Computer Science](https://link.springer.com/book/10.1007/978-1-4471-6639-9)：计算机论文写作的系统参考；可先从图书馆查阅。
- [The Craft of Research](https://press.uchicago.edu/ucp/books/book/chicago/C/bo215874008.html)：从问题、论证到证据的通用框架；已出到第五版。
- [Overleaf Learn](https://www.overleaf.com/learn)：LaTeX、BibTeX 与协作写作。
- [Simon Peyton Jones: How to Give a Great Research Talk](https://www.microsoft.com/en-us/research/academic-program/give-great-research-talk/)：研究报告的结构与表达。

读论文时问“作者凭什么让我相信”，做实验时问“还有什么解释也说得通”。这两个问题比“能不能发”更早，也更重要。
