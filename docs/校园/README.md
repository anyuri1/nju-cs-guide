# 校园

先学会找入口。很多“信息差”，只是没有去正确的地方搜。

## 六个该记住的入口

- [南京大学本科生院](https://jw.nju.edu.cn/)：培养方案、教务通知、创新训练。选课和毕业要求以你入学年份的文件为准。
- [南京大学计算机学院](https://cs.nju.edu.cn/)：学院通知、师资与课程主页。重要通知不要只等群聊转发。
- [南京大学网上办事服务大厅](https://ehall.nju.edu.cn/)：在读证明、场地、事务办理等统一入口。
- [南京大学信息化建设管理服务中心](https://itsc.nju.edu.cn/)：校园网、统一身份认证、邮箱和正版软件。
- [南京大学图书馆](https://lib.nju.edu.cn/)：馆藏、电子资源、馆际互借与培训；[已购数据库](https://libdb.nju.edu.cn/) 可以先查学校是否已经付过钱。
- [南京大学学生就业创业指导中心](https://job.nju.edu.cn/)：校招、实习、宣讲和就业手续。

系统入口可能调整；旧链接打不开时，回到对应部门首页找，不要在搜索结果里反复撞过期页面。

## 找资料的顺序

1. 在学校或学院官网搜标题关键词；
2. 确认发布单位、发布日期和适用年级；
3. 仍有歧义，再问教务员或辅导员；
4. 学长学姐的经验用来理解文件，不用来替代文件。

## 培养方案怎么读

培养方案是你和学校之间的四年合同，值得在大一开学前读一遍原文。这里只讲**该盯哪几处**，具体数字以你入学年份的版本为准——仓库不替你解释政策。

**一、先看学分构成。** 通常分四块：通识通修、学科专业、多元发展、毕业论文。看清各自是必修还是选修、各占多少，就知道选修的余地有多大。

**二、通识课里有“必修项”，不是修满学分就行。** 除了总学分，往往还要求必须包含若干特定项目（人工智能通识核心课、悦读经典、美育、劳动教育等）。漏掉一项，学分再多也毕不了业。

**三、准入：哪几门要先修出来。** 准入课程通常安排在大一。想进这个专业，大一就得把它修掉。

**四、准出：门数 + 学分 + 课程名单。** 这是最容易被忽略的硬条件，通常要求完成指定的若干门课程并取得相应学分。**照着名单核对自己修过的课**，不要只看学分总数。

**五、先修关系看拓扑图。** 仓库保留了一张 [2025 年课程拓扑图](../assets/2025-CS-本科课程-拓扑图.png) 作为**历史参考**，不是你这一届的选课依据。读它主要看五条线：

- 数学线：微积分 → 线性代数 → 概率论
- 程序线：程设 / SICP → 离散数学 → 数据结构 → 算法设计与分析
- 系统线：数字逻辑与计算机组成 → 计算机系统基础 → 操作系统 → 计算机体系结构
- 网络线：计算机网络
- 实验线：数字逻辑与计算机组成实验 → 计系设计 / 大数据 / 软件工程综合实验

**先修没修上，后面一整条线都会被推迟。** 这就是为什么选课不能只看“这门课好不好过”。

> 课程名、学分、准入准出和推免办法每届都可能改。仓库不转载培养方案原文（属学校文件，且逐年更新），请到[本科生院](https://jw.nju.edu.cn/)或学院教务员处获取你那一届的正式版本。

## 论文

- 找论文先用 [Google Scholar](https://scholar.google.com/) 或 [DBLP](https://dblp.org/) 找到准确题目、作者和 DOI，再从图书馆数据库进入出版商页面。校外访问按信息化中心和图书馆当年的说明操作；不要把来路不明的代理当成学校服务。
- 也可以直接在 [arXiv](https://arxiv.org/) 或会议、期刊官网找；三者并不互斥。
- 校外访问的合规渠道只有学校提供的那两个：VPN，以及 [CARSI](https://www.carsi.edu.cn/)（高校联合采购的统一认证，很多数据库可用学号直接登录，不必走 VPN）。图书馆没买的文献走馆际互借或文献传递。

## 软件

学校可能提供 JetBrains、Microsoft、MATLAB 等软件授权。安装前先查信息化中心；没有写在官方页面上的“校园版”，就当它不存在。
