# 校园

先学会找入口。很多“信息差”，只是没有去正确的地方搜。

## 六个该记住的入口

- [南京大学本科生院](https://jw.nju.edu.cn/)：培养方案、教务通知、创新训练。选课和毕业要求以你入学年份的文件为准。
- [南京大学计算机学院](https://cs.nju.edu.cn/)：学院通知、师资与课程主页。重要通知不要只等群聊转发。
- [南京大学网上办事服务大厅](https://ehall.nju.edu.cn/)：在读证明、场地、事务办理等统一入口。
- [南京大学信息化建设管理服务中心](https://itsc.nju.edu.cn/)：校园网、统一身份认证、邮箱和正版软件。
- [南京大学图书馆](https://lib.nju.edu.cn/)：馆藏、电子资源、馆际互借与培训；[已购数据库](https://libdb.nju.edu.cn/) 可以先查学校是否已经付过钱。
- [南京大学学生就业创业指导中心](https://job.nju.edu.cn/)：校招、实习、宣讲和就业手续。

校内课程还会用到 [SPOC](https://study.nju.edu.cn/home/index.mooc)。系统入口可能调整；旧链接打不开时，回到对应部门首页找，不要在搜索结果里反复撞过期页面。

## 找资料的顺序

1. 在学校或学院官网搜标题关键词；
2. 确认发布单位、发布日期和适用年级；
3. 仍有歧义，再问教务员或辅导员；
4. 学长学姐的经验用来理解文件，不用来替代文件。

培养方案尤其如此。课程名、学分、准入准出和推免办法都会改。仓库保留了一张 [2025 年课程拓扑图](../assets/2025-CS-本科课程-拓扑图.png) 作为历史参考，但它不是你这一届的选课依据。

## 论文

- 找论文先用 [Google Scholar](https://scholar.google.com/) 或 [DBLP](https://dblp.org/) 找到准确题目、作者和 DOI，再从图书馆数据库进入出版商页面。校外访问按信息化中心和图书馆当年的说明操作；不要把来路不明的代理当成学校服务。
- 也可以直接在 [arXiv](https://arxiv.org/) 或会议、期刊官网找；三者并不互斥。

## 软件

JetBrains、Microsoft、MATLAB 等软件在信息化中心一般都有免费版。  
不过授权范围会变化，安装前先查信息化中心；没有写在官方页面上的“校园版”，就当它不存在。
