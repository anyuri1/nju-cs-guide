# 升学

“读研”不是一个选项，而是几种成本、训练方式和出口都不同的选择。先弄清自己为什么要读，再看学校和排名。

## 考研

- [中国研究生招生信息网](https://yz.chsi.com.cn/)：招生目录、报名、初试成绩、调剂等官方入口。
- [南京大学研究生招生网](https://yzb.nju.edu.cn/)：南大招生简章、专业目录、复试和录取信息。
- [南京大学计算机学院](https://cs.nju.edu.cn/)：学院复试办法、名单和培养信息。
- [王道论坛](https://www.cskaoyan.com/)：408 与院校经验的社区资料；考试科目和参考书必须回到招生目录核对。

先确定目标年份的考试科目，再倒排数学、英语、政治和专业课。不要拿上一届截图当招生简章。

## 海外硕士与博士

- [Applying to Ph.D. Programs in Computer Science](https://www.cs.cmu.edu/~harchol/gradschooltalk.pdf)：Mor Harchol-Balter 的经典指南，先判断 PhD 的工作方式是否适合自己。
- [CSRankings](https://csrankings.org/)：按研究领域和公开论文数据查看院系；它适合发现导师，不适合替你做最终决定。
- [CS-SOP](https://cs-sop.org/)：公开的 CS 申请文书与建议，用来观察结构，不要套写别人的人生。
- [Open CS Application](https://opencs.app/)：申请资源与项目信息聚合。
- [TOEFL](https://www.ets.org/toefl/test-takers/ibt.html)、[GRE](https://www.ets.org/gre/test-takers/general-test.html)、[IELTS](https://www.ielts.org/)：考试政策、送分和有效期只看官方页面。

硕士申请通常更看课程、成绩、匹配度和实习；研究型项目与博士更看研究经历、推荐信和方向匹配。这里只能当作起点，具体项目必须逐个读 admissions、funding 和 faculty 页面。

## 做决定前问五个问题

1. 我想获得的是研究训练、职业门槛、转方向，还是延后选择？
2. 这个项目的课程、导师和毕业去向是否支持它？
3. 总成本是多少，包括时间、学费和机会成本？
4. 如果没有理想导师、奖学金或实习机会，我还愿意去吗？
5. 申请失败时，我的备选方案是什么？

把这些答案写下来。一个能被修改的计划，比脑中一团“再看看”可靠。
