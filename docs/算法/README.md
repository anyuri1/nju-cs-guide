# 算法

课程讲的是原理，刷题练的是把它变成手速。这两件事不能互相替代：只会原理，机试写不出来；只会套路，面试深挖就穿帮。

保研机试、考研 408、实习面试的算法环节都考这个，而它靠的是长期积累——**每周三到五题、坚持两年，比考前突击一百题有用**。

## 先建直觉，再上量

- [Hello 算法](https://www.hello-algo.com/)：动画图解加可运行代码，第一次学数据结构不劝退。之后应尽快转向证明和题目。
- [代码随想录](https://programmercarl.com/)：按专题组织的刷题路线与题解，和 LeetCode 配合用。
- [OI Wiki](https://oi-wiki.org/)：算法与数据结构百科，长期查阅型，不要从头读到尾。

算法本身的课程资源（6.006、CS61B 等）见[课程](../课程/README.md)。

## 平台

- [LeetCode 中国站](https://leetcode.cn/problemset/)：面试向，中文题面，国内访问快。
- [洛谷](https://www.luogu.com.cn/)：题单体系适合从零打基础。
- [Codeforces](https://codeforces.com/)：div3 / div4 适合练手速与思维。
- [牛客](https://www.nowcoder.com/)：校招笔试真题与面经。
- [AtCoder](https://atcoder.jp/)：另一套日文 / 英文题库与线上赛。

## 怎么刷

**建议顺序**：数组 → 链表 → 哈希表 → 字符串 → 双指针 → 栈与队列 → 二叉树 → 回溯 → 贪心 → 动态规划

- **按专题刷，不按题号刷。** 题号是随机的，专题才有结构。
- **每题限时。** 超时就看题解，但要**第二天不看答案重做一遍**。
- **建立“题型 → 模板”的映射**，而不是背题。换个背景就认不出来，说明还没学会。
- 数量不是验收标准，**能复述解法才是**。
