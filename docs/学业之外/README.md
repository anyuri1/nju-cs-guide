# 学业之外

绩点是门槛，它决定你有没有资格；入党、学生工作、志愿服务和思想成长决定门槛之上你排第几。

这几件事的共同点是**有时间窗**：大一错过学生工作的窗口，大三补不回来；入党从递交申请书到成为预备党员要两年出头，临时凑不出来。

## 先看清四件事的位置

| 项 | 记在哪 | 什么时候开始 |
| --- | --- | --- |
| 学业 | 学分绩、专业排名 | 大一 |
| 学生工作 | 班委、团支书、学生会、社团 | 大一，这是最容易进的窗口 |
| 志愿服务 | [学生第二课堂](https://youth.nju.edu.cn/tw/)的志愿时长 | 每学期 |
| 思想成长 | 入党流程 | 大一上就该递交申请书 |

它们最终落到三个地方：评奖评优、保研的加分与党团民主评议、简历上的“在校经历”一栏。

## 入党

阶段大致是这样：

```text
递交入党申请书 → 入党积极分子 → 青共校 / 党课结业 → 发展对象、预备党员 → 预备期满转正
    大一上            约半年后                              约两年后            再一年
```

- **从递交申请书到成为预备党员，通常要两年出头。** 想走这条路，大一上就该交；大三才想起来基本来不及。
- 学生工作、志愿服务、定期思想汇报都会进档案，**临时补不出来**。
- 各学院的批次和时间点不同，具体流程问辅导员或学院党委，以上级通知为准。

## 学生工作

班委、团支书、学生会、社团都可以，**大一是最容易进的窗口**——不少岗位到二年级就不再招新。

选一到两个能真正参与的，别铺满。学业塌了，学生工作救不回来。

## 志愿服务与五育

- [学生第二课堂](https://youth.nju.edu.cn/tw/)：志愿时长记在这里，评奖评优和保研都要看。常见来源是迎新、支教、社区服务、赛事志愿者和书院活动。
- [五育项目管理系统](https://ndwy.nju.edu.cn/dztml/)：德智体美劳的记录。

**每学期去看一眼**，别到毕业才发现没攒够。

## 评奖评优看什么

人民奖学金、国家奖学金、优秀学生等，通常综合看学业成绩（门槛）、学生工作、志愿服务、思想成长、竞赛与科研。

具体权重和门槛每年、每个奖项都不同，以当年学院通知为准。冲高等级奖项时答辩环节也很关键，讲稿和材料要提前准备。

## 怎么问学长学姐

这是最有效、也最容易被浪费的资源。差别只在问法。

| 没人愿意回 | 对方愿意聊 |
| --- | --- |
| “学长，保研要准备什么？” | “学长，我想保研，现在专业排名 20% 左右，大二应该优先补绩点还是先进实验室？” |

说清自己的情况，问一个具体的**选择题**，问完给对方一个反馈。

一次好的提问，能换回一段长期关系。
