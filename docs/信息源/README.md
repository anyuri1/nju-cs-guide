# 信息源

信息不是查一次就完了，是要持续收的。

这一页只做两件事：列出值得长期盯的入口，以及给一条判断标准——**先看发布单位和发布日期**，再看是谁说的。

## 校内：最重要，也最常被忽略

- [南京大学计算机学院](https://cs.nju.edu.cn/)：学院通知、选拔办法、结果公示。**重要通知只在这里发**，群聊转发一定滞后，而且可能只剩半句。
- [南京大学本科生院](https://jw.nju.edu.cn/)：教务通知、培养方案、创新训练。
- 书院公众号 / 学院公众号：日常活动、讲座、奖学金。更新快，但**不完整**——能当提醒，不能当依据。
- 学长学姐：最有效，也最被浪费。问法见[学业之外](../学业之外/README.md)。

**每周固定看一次学院官网通知页，比订阅十个公众号管用。**

## 技术信息源

- [GitHub Trending](https://github.com/trending)：每天在流行什么，也是找练手项目的来源。
- [Hacker News](https://news.ycombinator.com/)：英文技术圈的风向。
- [InfoQ 中文站](https://www.infoq.cn/)：工业界在用什么。

论文、会议和文献工具不放这里，见[科研](../科研/README.md)。

## 社区

- [知乎](https://www.zhihu.com/)：挑几个高质量答主关注，不要刷时间线。
- [牛客](https://www.nowcoder.com/)：校招、笔试与面经。
- [一亩三分地](https://www.1point3acres.com/)：留学与北美就业。

社区信息适合发现机会和理解行情，**不适合确认资格**。看经验帖时先记下作者的年份、学校、方向和结果；缺了这些上下文，经验只剩情绪。

## 两个反模式

- **收藏不等于学会。** 收藏夹是坟场。看到就做，做不完就删。
- **别被“大厂 P7 教你……”式内容带节奏。** 这类内容的目标是流量，不是你的成长。
