# 课程

公开课不是用来收藏的。给本学期正在学的一门课找一个补充资源，做完作业，比看完十门课的第一讲有用。

## 先看地图

- [CS 自学指南](https://csdiy.wiki/)：中文课程地图，适合按方向找公开课和实验。
- [Teach Yourself Computer Science](https://teachyourselfcs.com/)：用九个主题解释一个 CS 本科生应补什么。
- [OSSU Computer Science](https://github.com/ossu/computer-science)：接近完整培养方案的自学路线；适合长期规划，不适合一口吞。
- [MIT OpenCourseWare](https://ocw.mit.edu/search/?d=Electrical%20Engineering%20and%20Computer%20Science)：MIT 公开课总入口。
- [中国大学 MOOC](https://www.icourse163.org/) 与 [学堂在线](https://www.xuetangx.com/)：国内课程的稳定入口。

选择时看三样东西：先修要求、作业是否公开、你能不能留出每周固定时间。名校校徽不算学习资源，作业和反馈才算。

## 按课找资源

### 编程与程序设计

- [Harvard CS50x](https://cs50.harvard.edu/x/)：从 C 到 Python、SQL 和 Web，讲义、作业和开发环境完整；适合第一门编程课。
- [Berkeley CS61A](https://cs61a.org/)：用 Python 讲抽象、递归、解释器；适合已经会写一点程序的人。
- [Structure and Interpretation of Computer Programs](https://web.mit.edu/6.001/6.037/sicp.pdf)：SICP 原书；不要赶进度，边读边做题。
- [南京大学《计算机程序的构造和解释》](https://sicp.pascal-lab.net/)：SICP 路线的本校课程材料。

### 离散数学、数据结构与算法

- [MIT Mathematics for Computer Science](https://courses.csail.mit.edu/6.042/spring18/mcs.pdf)：证明、图、计数、概率；离散数学的免费教材。
- [Berkeley CS61B](https://sp21.datastructur.es/)：数据结构与工程化编程，项目比视频更值得做。
- [MIT 6.006](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)：算法设计、正确性与复杂度分析，含讲义、题目和解答。
- [Hello 算法](https://www.hello-algo.com/)：图解与可运行代码，适合第一次接触数据结构；之后应尽快转向证明和题目。
- [OI Wiki](https://oi-wiki.org/)：竞赛算法百科，适合查概念，不是一条从头读到尾的路线。

要动手练的话，刷题平台和练习顺序见[算法](../算法/README.md)。

### 计算机系统与体系结构

- [Nand2Tetris](https://www.nand2tetris.org/)：从逻辑门搭到计算机、汇编器和小型语言，适合建立全栈的系统直觉。
- [Berkeley CS61C](https://cs61c.org/)：C、RISC-V、缓存、并行；配套实验完整。
- [CMU 15-213 / CS:APP](https://www.cs.cmu.edu/~213/)：程序如何在机器上执行。课程明确把 labs 视为核心，别只看书。
- [南京大学计算机系统基础](https://cs.nju.edu.cn/sufeng/course/ics/) 与 [ICS Wiki](https://njuics-wiki.github.io/ics-wiki/)：本校课程入口与学生维护的补充说明。
- [南京大学 PA](https://nju-projectn.github.io/ics-pa-gitbook/ics2024/)（[代码仓库](https://github.com/NJU-ProjectN/ics-pa)）：用模拟器把指令、运行时和操作系统串起来；文档有年份，开始前先看仓库当前分支。

### 操作系统

- [南京大学《操作系统原理》](https://jyywiki.cn/OS/2026/)：讲义、代码、录像和实验一体；优先跟当年主页。
- [Operating Systems: Three Easy Pieces](https://pages.cs.wisc.edu/~remzi/OSTEP/)：围绕虚拟化、并发和持久化展开的免费教材，并提供模拟作业。
- [MIT 6.1810 / xv6](https://pdos.csail.mit.edu/6.1810/)：小型 Unix 教学内核；适合已经学过 C 和计算机系统的人。

### 计算机网络

- [Stanford CS144](https://cs144.stanford.edu/)：从字节流和 TCP 接收端开始写一个网络栈；实验负担不轻。课程网站每学年重建，旧年份地址会失效，以当年主页为准。
- [Computer Networking: A Top-Down Approach](https://gaia.cs.umass.edu/kurose_ross/index.php)：自顶向下教材的作者站，含 Wireshark labs 和 slides。
- [南京大学计算机网络](https://cs.nju.edu.cn/sufeng/course/net/)：本校课程入口。

### 数据库与分布式系统

- [CMU 15-445](https://15445.courses.cs.cmu.edu/)：数据库内核课程，公开视频、讲义和 BusTub 项目齐全。
- [Berkeley CS186](https://cs186berkeley.net/)：数据库系统基础，notes 适合查漏补缺。
- [MIT 6.5840](https://pdos.csail.mit.edu/6.824/)：分布式系统经典课程；先有操作系统、网络和并发基础再做 labs。

### 编译、程序语言与软件构造

- [Crafting Interpreters](https://craftinginterpreters.com/)：从零实现两个解释器，叙述和代码都完整。
- [Programming Languages: Application and Interpretation](https://www.plai.org/)：从解释器出发理解程序语言。
- [LLVM Kaleidoscope Tutorial](https://llvm.org/docs/tutorial/MyFirstLanguageFrontend/index.html)：用 LLVM 实现一门小语言的前端与 JIT。
- [南京大学编译原理](https://cs.nju.edu.cn/changxu/2_compiler/index.html)：本校课程与实验入口。
- [MIT 6.031 Software Construction](https://web.mit.edu/6.031/www/sp21/)：规格、测试、抽象数据类型与并发；适合从“能运行”走向“能维护”。

### 人工智能与机器学习

- [南京大学《机器学习导论》](https://www.lamda.nju.edu.cn/yehj/ml2026/)：本校课程，课件、阅读和作业要求清楚。
- [Stanford CS229](https://cs229.stanford.edu/)：机器学习的数学主线；先补线性代数、概率和微积分。
- [Dive into Deep Learning](https://zh.d2l.ai/)：可运行 notebook 的免费教材，有中文版本。
- [Stanford CS231n](https://cs231n.stanford.edu/)：计算机视觉与深度学习，notes 长期可用。
- [fast.ai](https://course.fast.ai/)：从可用模型出发再补理论，适合项目驱动的人。

### 图形学与安全

- [GAMES101](https://sites.cs.ucsb.edu/~lingqi/teaching/games101.html)：中文现代计算机图形学入门，课程主页含讲义和作业。
- [CMU 15-462](https://15462.courses.cs.cmu.edu/spring2024/lectures)：图形学讲义、视频与阅读，适合继续深入。
- [pwn.college](https://pwn.college/)：亚利桑那州立大学维护的动手安全课程；在合法环境里学习漏洞与防护。
- [Cryptopals](https://cryptopals.com/)：用编程题理解密码系统常见构件与攻击。
