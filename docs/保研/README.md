# 保研

这里不提供“今年前多少名稳了”，也不预测某个实验室会不会捞人。推免资格、加分规则和接收办法每年都可能变化；真正值得收藏的是发布入口。

## 三个官方入口

- [南京大学研究生招生网](https://yzb.nju.edu.cn/)：学校层面的夏令营、预推免、接收推免生与直博通知。
- [南京大学计算机学院](https://cs.nju.edu.cn/)：学院层面的选拔办法、报名通知与结果公示。
- [教育部推免服务系统](https://yz.chsi.com.cn/tm/)：注册、填报志愿、确认复试和待录取通知的全国统一系统。

任何经验帖都应与这三个入口交叉核对。留意适用年份、发布单位、报名系统、截止时间和附件；正文里的一个“须”字，往往比群里一百条消息重要。

## 粗略时间线

| 时间 | 该做什么 |
| --- | --- |
| 大一至大二 | 把课程学明白；建立项目、科研或竞赛中的一种长期积累 |
| 大三上 | 了解本院资格规则；整理成绩、排名、简历和材料清单 |
| 大三下 | 跟踪夏令营通知；按项目分别准备材料和考核 |
| 暑假至九月 | 参加夏令营、预推免；持续核对本校资格与目标院系通知 |
| 系统开放后 | 在教育部系统完成最终志愿与确认动作 |

这是观察窗口，不是当年日历。所有日期以当期通知为准。

## 社区资料怎么用

- [CS-BAOYAN Wiki](https://csbaoyan.top/)：院校、方向、材料与经验的社区索引。
- [CS-BAOYAN DDL](https://ddl.csbaoyan.top/)：报名截止日期聚合；发现目标后回到院系官网确认。
- [CS-BAOYAN GitHub](https://github.com/CS-BAOYAN)：往年经验与开放资料。

社区信息适合发现机会和理解黑话，不适合确认资格。看经验帖时记录作者的年份、学校背景、方向和结果；缺了这些上下文，经验只剩情绪。

## 材料清单

- 一页中文简历，必要时再做英文版；
- 成绩单、排名证明和在读证明；
- 个人陈述，以及针对不同项目调整的短版说明；
- 能讲清楚的课程项目、科研或竞赛材料；
- 通知要求的推荐信、证件与承诺书；
- 一张自己的投递表：项目、入口、截止时间、材料、状态。

不要用十个仓库名代替一个讲得明白的项目。面试会沿着简历往下问，写上去的每个名词都应当经得起三次“为什么”。
