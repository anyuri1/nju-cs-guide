# 路线

前面几页回答“去哪儿找资源”，这一页回答“什么时候做什么”。

四年的时间窗是固定的：先修课排在前面，夏令营和秋招有截止日，入党要两年出头。**错过一个窗口，往往要多花一年**——这也是信息差里最贵的一种。

## 四年地图：八个学期，六条线

同一条线在不同学期并行推进，长度就是它的时间窗：

| 线 | 时间窗 | 内容 |
| --- | --- | --- |
| **数理地基** | 大一上 – 大二下 | 微积分 · 线性代数 · 离散数学 · 概率论 |
| **编程与算法** | 大一上 – 大三上 | 程设 / SICP · 高级程序设计 · 数据结构 · 刷题 |
| **专业核心** | 大二上 – 大三下 | 计组 · 操作系统 · 计算机网络 · 数据库 · 编译 |
| **科研** | 大二下 – 大四上 | 进组 · 大创 · 暑期科研 |
| **竞赛** | 大一下 – 大三下 | 数模（国赛 / 美赛）· 蓝桥杯 · CSP · ICPC · Kaggle |
| **升学 / 求职** | 大三上 – 大四下 | 保研 · 考研 · 申请 · 秋招 |

读这张表只看一件事：**每条线什么时候开始。** 课程先修关系见[培养方案怎么读](../校园/README.md#培养方案怎么读)；这张表看的是课外的时间窗。

## 四个检查点

| 时间 | 检查什么 |
| --- | --- |
| **大二上** | 开始接触科研：读两篇目标方向的论文，带着它们去发邮件。越早开始越从容，但不必急着进组；别群发模板。 |
| **大三上** | 定一条主线：保研 / 考研 / 出国 / 就业，定一条，留一个备选。现在不用决定，但要知道**什么时候必须决定**。 |
| **大三上** | 备材料：申请材料最好在这一年备好。拖到大三下才开始会很赶。 |
| **大三下** | 投暑期实习：秋招前最重要的一次机会，有转正名额。有能讲清楚的项目，面试才聊得下去。 |

四条都不需要现在就完成，需要的是**知道它们存在**。

## 三条动作，每条都有验收

看完不等于做过。这三件事成本很低，但都有可以检查的结果：

| 时间 | 做什么 | 验收 |
| --- | --- | --- |
| **今晚** | 用学校渠道（CARSI 或图书馆代理）下载 1 篇论文 | 本地多了一个 PDF |
| **本周** | 建一个带 README 的仓库，完成第一次 commit | GitHub 上有 commit 记录 |
| **本月** | 带 3 个具体问题，约谈 1 位学长学姐 | 问完给对方一个反馈 |

## 自查清单

大一结束时，这些应该都能打勾：

- [ ] 会用 CARSI，能下到 ACM / IEEE 的论文
- [ ] GitHub 账号已注册，有第一个 repo
- [ ] Git 会用 `add` / `commit` / `push`
- [ ] 知道怎么装 Git 和 gcc，跑通过 hello world
- [ ] LeetCode 刷了 10 题
- [ ] 知道 csdiy.wiki 和 OI-Wiki 是什么
- [ ] 关注了学院官网通知页
- [ ] 读完了《How to Read a Paper》
- [ ] 会用一个 AI 编程工具
- [ ] 完成过一次具体请教，并在事后给了反馈

信息差不会自己消失。它只会从“你不知道”，变成“别人已经做完了”。
