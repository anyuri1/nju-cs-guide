# NJU CS 本科资源指南

这不是第二份培养方案，也不打算把专业课再讲一遍。

它只做一件事：当你知道自己缺什么时，告诉你去哪里找。链接按“官方通知、课程主页、原作者文档、社区整理”的顺序选择；会变的政策，只给入口，不替学校作解释。

> 面向南京大学计算机学院本科生。资源只作索引，请以各网站当前内容为准。
